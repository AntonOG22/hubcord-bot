Why does Emerald ask for Administrator access?

When you invite Emerald, Discord shows an Administrator permission request. That's a broad ask, so here's exactly why:

  • Tickets need their own channels and categories. Creating a ticket channel, moving it between categories on close/reopen, and setting who can see it requires channel-management permissions in every category — not just the ones picked ahead of time.
  • Moderation has to work everywhere. Kicking, banning, timing out, purging messages, and applying slowmode only work reliably if the bot isn't blocked in some channel by a permission it wasn't explicitly given.
  • Roles need to sit above the ones they manage. Giveaway roles, self-assign role panels, auto-role on join, and reaction roles all require the bot's own role to be positioned correctly and able to assign/remove roles server-wide.
  • It's simpler and less fragile than picking permissions one by one. A narrower permission set would need updating every time you use a new feature or create a new channel — Administrator avoids random "missing permission" failures down the line.

What Administrator access does not mean: it doesn't give Emerald — or anyone using the dashboard — access to any server you haven't explicitly logged into and been confirmed by Discord to manage. Every dashboard action is still re-verified live against your actual Discord permissions on every request (see the Terms for the full breakdown). You can always review or remove the bot's role and its permissions directly in your own Discord server settings at any time.
