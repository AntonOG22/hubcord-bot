1. What Emerald is

Emerald is a free, multi-server Discord moderation and utility bot with a web dashboard. Anyone can invite it to a server they manage, and anyone can log in with their own Discord account to configure any server where Discord confirms they hold Manage Server (or Administrator, or ownership). There is no shared password — every dashboard session is a real Discord login.

2. Who can use it

4. What data we collect and why

We collect only what's needed to run the bot and the dashboard:

  • From Discord OAuth login: your Discord user ID, username, and avatar, plus the list of servers you're in and your permission level on each — used only to decide which servers you're allowed to see and manage here. We never see or store your Discord password.
  • Per-server bot configuration and activity: settings you configure (channels, roles, prefixes, automod rules), moderation records (warnings, tickets, audit log entries), leveling/XP data, and similar operational data — all scoped to that one server.
  • Message content: read only where a feature requires it in real time (automod filtering, counting game, sticky messages, XP, custom commands) to decide whether to act — not stored as a general log or archive.

Your dashboard session is stored in a signed browser cookie, not a server-side session database. Every guild-scoped request is re-verified live against Discord's API — a stale cookie alone is never enough to access a server's data.

5. Data isolation between servers

One server's data — tickets, warnings, XP, settings, audit log — is never shown to admins of a different server. There is intentionally no global inbox, cross-server log, or "view all DMs" feature in this dashboard, because that would leak one server's private activity to unrelated server admins.

6. Data retention & deletion

Per-server data is kept for as long as the bot remains in that server (so settings survive a bot restart). Removing Emerald from a server does not instantly erase that server's stored data, but it stops all further collection for it. To request deletion of a specific server's data, contact us using the details below.
